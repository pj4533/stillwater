`scripts/prepare-v2-art.py` reproducibly adapts2048x683 originals to960x160:
480x80 downsample, nearest-neighbor upscale for user-requested pixelation, then
continuous scalloped canopy/rootbed darkening at text positions. The complete
scene is retained. Runtime reads only predecoded BGR565 `.bin` files with1024px
row stride; no Pillow dependency. Native envelope/FX telemetry displaces source
material within registered role-specific regions. Typography is drawn afterward.
